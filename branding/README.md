# Mów 1000 brand assets

The canonical mark is `mow-1000-icon-master.svg`.

- Bubble: `#2D6F67`
- Numeral upper split: `#FFFDF8`
- Numeral lower split: Polish red `#DC143C`
- Canvas: `#FFFDF8`

The outer canvas is always a full square. Platform launchers and stores apply
their own rounded masks; no corners or shadows are baked into the source asset.
The numerals use a horizontal 70/30 cream-to-red split and contain the only red
accent in the mark.

`android-adaptive-foreground.png` is the Android-specific safe-zone export. It
uses the same artwork at a smaller scale so the complete bubble remains inside
the adaptive icon mask.
